# 总纲（参考草案，未拍定）

## 故事一句话
他在梦里看着她死了无数次，却不知道她没有死；四十六亿年后，她化成一只狐狸来找他。

## 主线（草案）
- 男主醒于灵气复苏首日，地底旧天地第一批悬空归回。
- 诡物逼他入死地，四阶巅峰的狐狸救下他，一路跟随。
- 一道本源与他契合，Agent "有灵"，逐层解封，助他修行。
- 狐狸化形之日，他看清那张脸：正是梦里的女人。
- 后续：地下旧朝与旧敌逐批上来；她的灵身之死；一路飞升至混沌仙帝。【均待补】

## 第一幕（草案）
1. 梦中死别：反复的梦，醒来坐起，纯白棉被滑到腰间；窗外悬着一片不该悬着的山。
2. 先上来的是山：第一批山川市井无声悬空、缓慢移动；旧铺子有火，山上一闪人影。
3. 有灵：他的 Agent 开始有自己的小主意，会化成不相干的样子坐在他旁边。
4. 旧市井掉下一块石头：边缘落碎片，隔离带；他去看，裂口里爬出贴地无影的诡物，空气变薄，退不动。
5. 一只狐狸：四阶巅峰狐形救下他；她身上有梦里那女人的味道；她说她在找一个人。
6. 第一幕收束：她指给他看——第三批还要上来，更高也更近。他第一次觉得这些地底下的事和他有关。

## 待补

- 男主修为阶梯
- 她灵身之死的具体场景与代价
