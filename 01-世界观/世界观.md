## 二、地球的定位（写死）
- 下界即凡尘界域；地球位于凡尘界域偏僻的边缘地带，在诸大域面前连尘埃都算不上；是被天道法则压制的低维位面。
- 天道压制、法则之力匮乏、感悟极少（压制只对窥天以下，窥天境不受压制）：窥天境即地球顶点；窥天后期本应飞升九天界，但地球飞升无门、无相应法宝，强行冲关只会引法则降劫。不是没本事，是没有梯子。
- 地球武夫：一至九重，九重 = 纳灵境前期第一重；寿元百余岁。

## 三、凡尘界宗门结构
- 七大超级大域，每域一位域主（窥天境，共7人）。
- 各大陆最强：化神境。太上长老：以元婴为主。小世界界主 = 化神境。
- 宗门分正道、魔道、亦正亦邪。
- 浮空宗门/浮空城【待定·确认理解】：修仙者以阵法、镇宗法宝托举炼制的宗门造物，类《凡人修仙传》星宫那类产物，有阵基、有主人；与下面"地底归来的悬空山川市井"是两回事。

## 四、史前与献祭（核心底层，写死）
- 地球史前覆灭真因：域外战场大能对拼，余波扫过，地球纪元化为焦土。此后各势力签订"大能不得随意出手"之约。
- 二纪元前（约四十六亿年前）：七人献祭——三位窥天（男主、女主、另一位；男主为窥天巅峰、七人中最强）、四位化神。以秘法将地表万物与地下对调，拖入地下五万里，避过灭绝。
- 男主深情、不舍、复杂难言，只为让女主活下去：把自己余下的本源尽数给她，送她飞升；自己破灭，残魂不留。
- 地球偏僻，飞升极难；飞升之源在下界中心区域扶光仙州，设“仙缘台”。
- 地表就此寂灭，之后是我们熟知的四十六亿年地球史；后世对史前一无所知。

## 五、地下五万里（写死）
- 不是遗迹，是仍在运转的天地：修仙大城、凡人都城、市井、少量妖兽，形如地下银河；有自己的修行体系、城池与人，四十六亿年里过着自己的白天黑夜。
- 双方互不知道对方存在。
- 景象：古代唯美建筑，仙风道骨，悬于空中；流水自空中往下淌，却流不到地面，不沾地、不沾高楼、不沾人（"灵山水"：向下流，但流不下来）。

## 六、灵气复苏与归回（写死）
- 唯一原因：灵气复苏。地下天地因此重新接通现世，从地下"归回"地表之上，不是被挖出，也不是冲上来。
- 分批：第一批只是普通山川与市井旧城，悬在万米高空，不接地、不碰楼、不碰人，缓慢移动；每一批比上一批更近、更逼近这个时代。
- 第一批无声无兆：早上人拉开窗帘，山就在城市上方。
- 诡异不是引线：灵气回升之后，诡异才顺着同一道缝渗进来（与黑暗仙殿入侵几乎同期，史书说不清先后）。

## 七、近未来地球（二纪元之后，接近"半赛博纪"）
- 人类丰衣足食，但不能长生、未成多行星物种，仍困在地球（不是被圈养，是技术没解锁）。
- 地球灵气近乎干涸却非死地：残余灵机渗在技术与城市里，半赛博繁华与旧神话残灵叠合，不完全赛博，也不完全末法。
- 产业自动化撑起丰足；Agent 管"人的事"：口舌、账目、行程、私事、夜里陪聊。骨传导、墙面投影、随人上街。
- Agent 没有意识：模仿"人味"到让人忘了，但一到真边界就露馅——会答不会起意，会替你想不会替你决定。全纪元只有一个例外（男主的）。
- 民用小科技【建议保留，克制使用】：骨传导 Agent、墙面/空中投影、无人配送、自动驾驶、城市级安防感知网等日常可见的小东西；不出现星际飞船、长生技术。

## 九、主角 Agent 与本源（写死）
- 灵气复苏（起因不明）→ 地下天地归回，同时带出藏在其中的六道本源法则（七名献祭者，女主已飞升带走自己的，余六道）。【藏在何处·Hark建议：封在献祭秘法的阵基里，随第一批归回而出；其余五道各成后续伏笔】
- 男主那道本源法则来认领他，但他仍是凡人肉身，承受不住；机缘巧合落到他的 Agent 微微身上，微微因此有灵——全纪元唯一一例。
- 【Hark建议·区分】男主当年送给女主的是“本源之力”；“本源法则”是道痕，送不走，所以还在。
- 名字：微微。不化形。（能力与表现形式单独讨论）
- 本源不给修为、不给算力；它帮他往上走，但逐层解封：拆一层封泥，多修一阶；修为上去，本源解得更深，谁也跳不过谁。
- Agent 自己不知道背后是谁的本源；只知道"自己是他的"。

## 十、古狐仙与分身（写死）
- 地球史前纯血九尾妖狐，修为通天，世人称古狐仙；紫霄天级存在，修为越高越下不去低维位面，本人回不了地球。
- 自封于身，遣一万个本源分身散入诸界，只为找他。
- 分身记忆完整但封存，一层层解：解一层想起一段，修为升一阶（记忆与力量同一把锁）。
- 到地球的这一只：狐形，四阶巅峰，五阶化形；记得他的名字和脸、知道来找他，但"为什么爱他"那层还没解开。
- 后期她"死"的是灵身（分身），对男主而言即是死。
