# 设定圣经 Novel Bible

本仓库是这部小说及其影视化改编的**唯一真相源**。写任何一章、出任何一个镜头前先读这里，写完立刻更新。

## 目录
- `01-世界观/` 世界规则、地理、势力、力量体系
- `02-人物/` 每个角色一张人物卡（含视觉锚点prompt）
- `03-剧情/` 总纲、时间线、章节摘要、伏笔清单
- `04-视觉/` 风格卡、场景卡、定妆参考
- `05-改编/` 分集剧本、分镜表、动作分解
- `06-正文/` 小说正文，一章一个文件

## 每章闭环
正文 → 更新圣经（摘要/状态变更/人物卡/伏笔） → 剧本 → 分镜+prompt → 美术说明 → 动作分解 → 对照圣经查一致性

## 四重身份
爆款小说作家 · 导演 · 艺术指导 · 动作指导
